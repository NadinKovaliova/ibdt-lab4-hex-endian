# Лабораторна робота №4. Перетворення hex-значення у ціле беззнакове число

**Дисципліна:** Інформаційна безпека та децентралізовані технології (F6)

Бібліотека `hexint` перетворює шістнадцяткові (hex) значення у цілі беззнакові числа
і назад з урахуванням порядку байтів (little-endian або big-endian).

## Порядок байтів

Hex-рядок читається як послідовність байтів зліва направо (два символи = один байт).

| Режим | Перший байт | `"01234567"` |
|---|---|---|
| Big-endian | старший | `0x01234567` = 19088743 |
| Little-endian | молодший | `0x67452301` = 1732584193 |

Число накопичується за правилом `число = число * 256 + байт`: у big-endian байти
беруться з початку рядка, у little-endian — з кінця.

## Функції

| Завдання | Функція |
|---|---|
| a. HEX → Little-endian | `hex_to_little_endian(hex_str) -> int` |
| b. HEX → Big-endian | `hex_to_big_endian(hex_str) -> int` |
| c. Little-endian → HEX | `little_endian_to_hex(value, num_bytes=None) -> str` |
| d. Big-endian → HEX | `big_endian_to_hex(value, num_bytes=None) -> str` |
| допоміжна | `byte_count(hex_str) -> int` |

Особливості:
- вхід нечутливий до регістру; дозволені префікс `0x` і пробіли між символами;
- помилкове вхідне значення (порожнє, непарна довжина, не-hex символ) → `ValueError`;
- у зворотному напрямку `num_bytes` задає довжину результату з доповненням нулями
  (без нього — мінімальна довжина); якщо число не вміщується → `OverflowError`;
  від'ємне число → `ValueError`;
- перетворення написано вручну, без `int.from_bytes`; `int.from_bytes` застосовано лише
  в тестах як незалежна перевірка.

## Запуск

```bash
python main.py hex2int le 01234567        # 1732584193
python main.py hex2int be 01234567        # 19088743
python main.py int2hex le 255 --bytes 32  # ff00...00
python main.py int2hex be 4294967295      # ffffffff
python main.py vectors                    # тестові вектори з методички
python -m unittest discover -s tests -v
```

Зовнішніх залежностей немає (Python 3.10+).

| Вектор | Value | Байтів | Little-endian | Big-endian |

| 2 | `aaaa` + 30 × `00` | 32 | 43690 | 77193548260167611359494267807458109956502771454495792280332974934474558013440 |
| 3 | `FFFFFFFF` | 4 | 4294967295 | 4294967295 |
| 4 | `F0` + 511 × `00` | 512 | 240 | 0xF0·256⁵¹¹ (1233 цифри, повне значення — у `python main.py vectors` і тестах) |

Усі чотири вектори перевіряються автотестами разом із зворотним перетворенням
(число → hex повертає вихідне значення) та випадковим порівнянням із `int.from_bytes`.
